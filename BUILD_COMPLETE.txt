===============================================================================
                     SUPPORT & TROUBLESHOOTING
===============================================================================

Backend Won't Start:
  - Verify Python 3.9+
  - Check: pip list | grep -E "fastapi|playwright|supabase"
  - Verify Supabase credentials in .env

WebSocket Connection Fails:
  - Ensure backend running on localhost:8000
  - Check browser console for CORS errors
  - Verify CORS_ORIGINS in config.py

No Pages Discovered:
  - Test URL in browser first
  - Verify Playwright: playwright install
  - Check backend logs

LLM Analysis Not Working:
  - Verify API key in .env
  - Check API quota/billing
  - Review backend logs for rate limiting

Performance Issues:
  - Adjust MAX_PAGES_PER_AUDIT in config.py
  - Check database indexes
  - Review Playwright timeout settings
